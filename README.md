# BilaNiumN1 Portfolio

Personal portfolio of Irga Andreansyah Setiawan (BilaNiumN1), student developer and systems builder based in Lembang, Indonesia.

**Live:** [the-portofolio.vercel.app](https://the-portofolio.vercel.app)

## Stack

- Next.js / Vinext (React 19)
- TypeScript
- Tailwind CSS 4 + shadcn/ui
- Vercel deploy

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Structure

- `app/page.tsx` — single-page portfolio (hero, work, process/skills, profile, contact, easter eggs)
- `app/globals.css` — Ember Ledger design tokens and layout
- `app/layout.tsx` — metadata and viewport
- `public/irga-profile.jpg` — identity portrait
